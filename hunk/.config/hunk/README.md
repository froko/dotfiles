# hunk

[hunk](https://www.hunk.dev/) is a review-first diff viewer that plays nice with
agents. It's fast, it looks good, and it works everywhere. The provided
configuration in this dotfiles repository only sets the theme to
`Catppuccin Mocha`.

`hunk log` is a command that shows the git log in a hunk view. It can be used to
quickly review changes in a repository.

`hunk diff` is a command that shows the git diff in a hunk view. It can be used
to quickly review changes in a repository.
